# tests - Python SDK tests (pytest / unittest)

Run from the repository root: `python -m pytest tests/ -v`. The LIVE files are skipped
unless `PDB_NATIVE_PORT` is set (the differential file also needs `PDB_PG_DSN`,
a throwaway PostgreSQL 17) (a `--no-auth` server on `PDB_NATIVE_HOST`,
default 127.0.0.1); everything else needs no server. Nothing here needs
pyarrow except the decoder-parity and `query_arrow` checks, which skip without it.

Constraints: fake-server tests wait for the server to RECORD a frame
(`wait_for`) before asserting on it -- frames are recorded asynchronously.
Never patch `time.sleep` globally (other tests' threads use it): the retry
backoff is `particledb.pdb_wire._sleep`.

Source-file census checks read UTF-8 explicitly. The stalled-write fixture
constrains both TCP send and receive buffers, then fills the paused peer's
queue until a real nonblocking send refuses more bytes. This establishes
backpressure before the driver is timed, including on Windows loopback.
The fixture retains the same timeout,
SQLSTATE, connection-closure and no-reconnect assertions.

The unread-stream overflow regression opens the bounded request before creating its iterator. Events keep another request driving the reader until overflow is observed, so the test does not depend on consumer scheduling.
